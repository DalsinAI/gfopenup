# Media:midi

- GFOpenSynth (from its next release): the part carries the MIDI collection, 700 public domain pieces in a drawer per composer,
  and puts it in `Media:midi` where a volume named Media is mounted (the standard build's DH4:). Each file's
  source and licence is in `Media:midi/SOURCES.tsv`.
- GFOpenIcons gives `Media:midi` the Soft 3D folder with the sound mark where it has no icon.
