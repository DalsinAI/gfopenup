# MediaFiles:midi

- GFOpenSynth v1.0-rc3: the part carries the MIDI collection, 700 public domain pieces in a drawer per composer,
  and puts it in `MediaFiles:midi` where a volume named MediaFiles is mounted (the standard build's DH4:). Each file's
  source and licence is in `MediaFiles:midi/SOURCES.tsv`.
- GFOpenIcons gives `MediaFiles:midi` the Soft 3D folder with the sound mark where it has no icon.
