# Release notes for the next GFOpenUp pack: drive icons for Demos, Media and Emulation

For whoever builds the next pack. Paste these sections into that pack's RELEASE-NOTES.md.

## What's new

- The Demos:, MediaFiles: and Emulation: volumes get their own drive icons, drawn as the Games: one is: the Soft 3D hard
  disk with what the volume holds on it (a demo's colour bars and ball, a picture and a note of music, a processor).
  GFOpenIcons gives each to a machine that has the volume and leaves a machine without it alone.
